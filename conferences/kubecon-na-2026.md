## Tracks / Topics

1. **AI Inference + Agentic** — AI/ML workloads, inference, agents in cloud native
2. **Application Development + Delivery** — CI/CD, GitOps, developer workflows
3. **Cloud Native Experience** — General cloud native adoption and usage
4. **Cloud Native Novice** — Beginner-friendly content for newcomers
5. **Connectivity** — Service mesh, networking, API gateways
6. **Data Processing + Storage** — Databases, streaming, data pipelines
7. **Emerging + Advanced** — Cutting-edge and experimental topics
8. **Observability** — Monitoring, logging, tracing, OpenTelemetry
9. **Operations + Performance** — Cluster ops, scaling, reliability
10. **Platform Engineering** — Internal developer platforms, golden paths
11. **Security** — Supply chain, runtime security, policy, compliance

## What Reviewers Look For (Score High)

- Novel technical content not presented elsewhere
- Concrete demos, architectures, or implementation details
- Clear takeaways attendees can apply
- Open source focus (especially CNCF projects)
- Case studies with real metrics and lessons learned
- Diverse speaker lineups for panels

## Red Flags (Score Low / Reject)

- Sales or marketing pitches
- Vague or buzzword-heavy abstracts
- Content already presented at LF events in past 12 months
- AI-generated or low-effort proposals
- Closed-source or proprietary technology focus
- More than 3 submissions from same person
- Panels with 3+ speakers identifying as men
